# noble-community-repo

Открытая библиотека расширений сообщества для [noble](https://github.com/Lumanis45/noble). Приложение читает этот репозиторий напрямую с GitHub.

## Как опубликовать расширение

Пришлите pull request с папкой `plugins/<id>/`:

```
plugins/<id>/
  manifest.json   обязательно; "id" совпадает с именем папки
  plugin.js       точка входа (или файл из поля "main")
  *.js, *.svg     свои модули и картинки
```

И всё. **Реестра нет** — никаких `registry.json` и списков: приложение само находит папки `plugins/*/manifest.json`. После слияния CI соберёт архив `compressed/<id>.tar.zst` (его руками не трогайте).

Как писать расширения — полное руководство в `plugins/README.md` репозитория noble.

Ограничения для расширений сообщества:

- `"core": true` игнорируется — системными бывают только расширения noble-server;
- если `id` совпадает с системным расширением, в приложении останется системное;
- свои файлы импортируйте только относительным путём (`import { x } from './lib.js'`).
